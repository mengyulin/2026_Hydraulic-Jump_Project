每位學生負責「共同基準＋兩個個人變體」。一次只改一個指定物理因子，再檢查數值設定的影響，讓結果容易解釋。

兩組共十人。第一組 A1–A5 使用標準步法（Standard-step method，SS）、聖維南淺水方程（Saint-Venant，SV）及定常壓力近似 Boussinesq 模型（B）。第二組 B1–B5 使用 Python 標準步法與 HEC-RAS 6.6。同編號的兩位同學研究相同物理條件。

2. 哪些改變量會帶來連動？

  • 改上游坡度或粗糙度後，入口正常水深會重算，所以入口福祿數也會改變。
  • 改下游坡度時，仍固定出口水深與出口床高；上游的絕對床高因幾何積分而改變。不要把出口改成新的正常水深。
  • 改轉折長度時，保持中心與兩端坡度不變；轉折起、終點會移動。
  • 所有案例固定 L=30 mL=30\,\mathrm{m}L=30m、W=0.46 mW=0.46\,\mathrm{m}W=0.46m、總流量 Q=0.05413786 m3/sQ=0.05413786\,\mathrm{m^3/s}Q=0.05413786m3/s、g=9.81 m/s2g=9.81\,\mathrm{m/s^2}g=9.81m/s2、Cc=Ce=0C_c=C_e=0Cc​=Ce​=0。

本套件的數值核心限定上述渠寬與重力加速度，介面會拒絕其他值。請用既定案例選單開始，不直接改核心程式。

時間步與 CFL 是什麼？

時間步 Δt\Delta tΔt 是每次更新往前走的時間。CFL 為 Courant–Friedrichs–Lewy 條件的慣用縮寫，是控制更新步長的數值參數。對一般淺水波，可用下式理解其量級：

Cwave=(∣u∣+gh)ΔtΔx.C_{\mathrm{wave}}=\frac{(|u|+\sqrt{gh})\Delta t}{\Delta x}.Cwave​=Δx(∣u∣+gh​)Δt​.

程式還會考慮摩阻及其他穩定限制，B 另受高階空間項限制，所以輸入 CFL 不等於每一格、每一步都恰好滿足同一等號。基準設定為 SV 的0.4、B 的0.1；減半時分別用0.2、0.05，並查看實際時間步記錄。

為什麼要做固定耗散對照？

B 的 λ\lambdaλ 是 Rusanov 通量的數值耗散倍率，預設為1；κ=0.03\kappa=0.03κ=0.03 是額外濾波的係數，本專題保持固定。平滑區的主要人工擴散量級可用下式理解：

νnum∼λawaveΔx2,awave≈∣u∣+gh.\nu_{\mathrm{num}}\sim\frac{\lambda a_{\mathrm{wave}}\Delta x}{2},\qquad a_{\mathrm{wave}}\approx |u|+\sqrt{gh}.νnum​∼2λawave​Δx​,awave​≈∣u∣+gh​.

因此比較 N=1024,λ=1N=1024,\lambda=1N=1024,λ=1 與 N=2048,λ=2N=2048,\lambda=2N=2048,λ=2，可近似維持 λΔx\lambda\Delta xλΔx。波速仍會隨解改變，這不是精確固定物理黏性，也不是消除網格誤差的證明。它的用途是幫你判斷波峰改變有多少受到數值耗散影響。

5. 你的最低工作量

第一組：每案先做 N=512N=512N=512 起步檢查，再做 SV 與 B 各 N=1024,2048N=1024,2048N=1024,2048。三條件共12次主要 PDE 計算；PDE 是 partial differential equation（偏微分方程），在此指 SV 與 B。另選一個個人變體做 SV 半 CFL、B 半 CFL、B 的 N=2048,λ=2N=2048,\lambda=2N=2048,λ=2，以及 B off，共四次診斷。各案的標準步法另算。

第二組：每個條件各做三種斷面間距的 Python 與 HEC-RAS，共18份結果。先完成共同 P0，之後每人做自己的兩個變體。全組可以共享 P0，但每位學生必須懂得解釋其設定與驗收。

建議順序：第1–2週理解問題並重現 P0；第3–5週完成個人條件；第6–9週做解析度與控制對照；第10–12週與同編號同學核對、整理報告。更細的4096、8192網格不是全員必做項目。
