第二組操作：標準步法與HEC-RAS 6.6

教材入口完整講義問題設定三種方法案例分工結果判讀P0操作示範符號表

第一次操作：先跟做P0完整示範，附獨立Notebook、實際Python輸出與逐步判讀。

第二組比較 Python 標準步法與 HEC-RAS 6.6。重點是在同一組輸入下，比較水面高程、水躍所在斷面區間與警告訊息。

標準步法簡稱SS（Standard-step method），使用能量式追蹤水面分支，再以比力連接。HEC-RAS的全名為 Hydrologic Engineering Center's River Analysis System，本案使用一維定常混合流功能。共同問題是30 m長、0.46 m寬的坡度變化矩形渠道；詳細參數及方程見問題設定與標準步法。

步驟1：先在 Python 看懂 P0

沿用WSL，完成坡度套件安裝後，開啟 group_b.ipynb，保持 CASE_ID = "P0"，設定自己的學生代號。由上往下以Shift+Enter執行，得到三種斷面間距的標準步法水面。

三種間距為 0.5,0.25,0.125 m0.5,0.25,0.125\,\mathrm{m}0.5,0.25,0.125m。觀察加密後水躍位置是否改變；標準步法的垂直跳接不代表已算出物理水躍長度。

步驟2：開啟 HEC-RAS 原生專案

套件內 hec_ras/P0/ 已附三份P0範例，每個子資料夾各有一份 P0.prj。依檔案交換步驟複製到Windows本機工作目錄，再依HEC-RAS逐項核對頁開啟與計算。製作環境尚未實際運行HEC引擎，因此教師須先完成這一步，不能把附帶的Python參考當成HEC結果。

改做自己的 PnL、PnH 時，修改Notebook案例名稱後重新產生專案。每次輸出到新資料夾，保留不同版本。

# macOS／WSL用法；Windows改用 .venv\Scripts\python.exe 作前綴
.venv/bin/python lab.py run --case P2L --method ss --dx 0.125
.venv/bin/python lab.py hec --case P2L --output runs/P2L_hec_v1

步驟3：先確認「輸入完全配對」

HEC-RAS文字檔使用固定寬度數字欄位，總流量及床高會有很小的捨入。每份範例的 paired_ss.csv 是使用實際寫入HEC檔案的數值重算的Python標準步法，請以它作嚴格配對。這份檔案仍是Python結果。

P0的流量寫成 0.0541379 m3/s0.0541379\,\mathrm{m^3/s}0.0541379m3/s，與原值差 4×10−8 m3/s4\times10^{-8}\,\mathrm{m^3/s}4×10−8m3/s。expected.json 記錄實際寫入值；sections.csv 記錄斷面位置及床高。

步驟4：匯出 HEC-RAS 的實際結果

從 Profile Output Table（沿程剖面結果表）複製下列欄位，保留原始表格檔，再依 templates/hec_profile.csv 的表頭整理成UTF-8 CSV。只放單一案例、單一間距與單一流量剖面，不混入單位列。

from hec_tools import compare_export
result = compare_export(

    "my_P0_hec.csv",
    "runs/P0_hec_comparison_v1"
)

這段程式要在Notebook中執行；路徑需對應你真正計算的專案。它會檢查站號、總流量、缺值與福祿數是否合理，再產生水面差圖與跳接區間。若檢查不通過，先找單位、欄位或案例是否放錯，不直接放寬檢查值。

若HEC與Python差異超過斷面間距能解釋的程度，依序核對單位、入口坡度、尾水高程、摩阻平均及計算容許值，最後再加密。保留所有警告與臨界水深替代訊息，不先改 nnn 或尾水讓曲線重合。
