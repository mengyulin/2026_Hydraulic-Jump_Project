坡度變化渠道：大學生專題教材

教材入口完整講義問題設定三種方法案例分工結果判讀P0操作示範符號表

第一次操作：先跟做P0完整示範，附獨立Notebook、實際Python輸出與逐步判讀。

這是一份給大學生使用的水理專題教材。你將用同一條坡度改變的矩形渠道，學習設定計算問題、比較水理方法，並判讀水躍與水面波動。

第一次閱讀請從這裡開始：完整教學講義依序說明問題、方程式、案例與結果判讀；可離線閱讀，也可用瀏覽器列印。你不需要先讀任何研究對話或舊報告。

學完後，你應該能做什麼？

  • 說清楚渠道幾何、流量、粗糙度與兩端邊界條件。
  • 解釋標準步法、聖維南淺水方程與本套件 Boussinesq 型模型的差異。
  • 在條件一致的前提下，比較水躍位置、外側水深及波動。
  • 分辨物理條件改變與網格、時間步、數值耗散的影響。

建議閱讀與操作順序

  1. 問題設定：先看渠道示意圖、P0參數、正常水深與兩端邊界。
  2. 三種方法：理解 SS、SV、B 的全名、方程式與能算出的量。
  3. 案例與分工：確認自己的三個條件，以及一次只改什麼。
  4. 安裝與第一次執行：從既有GC1991的Windows／WSL環境加裝坡度套件，先完成P0。
  5. 第一組操作或第二組操作：照步驟完成個人案例與敏感度對照。
  6. 結果判讀與成果繳交：把可重跑的證據整理成報告。

本教材使用的名稱

簡稱完整名稱主要假設／方式本專題用途
SSStandard-step method／標準步法定常能量計算＋比力跳接水面分支、局部跳接位置；不算物理水躍長度
SVSaint-Venant equations／聖維南淺水方程深度平均、靜水壓、非穩態水深隨時間演變、平均水面與波動
BBoussinesq型模型／本套件的定常壓力近似加入部分非靜水壓修正定常水面與模型波列；非完整非穩態波浪模型
HEC-RAS 6.6Hydrologic Engineering Center's River Analysis System／河川分析系統本案選一維定常混合流與Python標準步法配對的工程計算

第一組有五人，使用 SS／SV／B；第二組有五人，使用 Python SS／HEC-RAS。學生代號 B1–B5 不代表他們使用 B 模型。數值參數與符號可隨時查閱縮寫與符號表。
