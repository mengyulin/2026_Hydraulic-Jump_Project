Notebook檔案：p0_group_b.ipynb（在Jupyter中開啟） · 兩組示範入口

P0是一座長 L=30 mL=30\,\mathrm{m}L=30m、寬 W=0.46 mW=0.46\,\mathrm{m}W=0.46m 的矩形渠道。水由左向右流，x=0x=0x=0 是入口，x=30x=30x=30 是出口；上游陡坡在 x=11x=11x=11 至 13 m13\,\mathrm{m}13m 平滑變成緩坡。固定流量與尾水後，觀察水流由淺而快變成深而慢的位置。

SS是Standard-step method（標準步法）；SV是Saint-Venant（聖維南淺水方程）；B是本套件的定常壓力近似Boussinesq型模型。HEC-RAS是Hydrologic Engineering Center's River Analysis System，本教學使用6.6的一維定常混合流計算。第一組使用SS／SV／B；第二組使用SS／HEC-RAS。

η(x)=zb(x)+h(x),q=QW,Fr=qgh3.\eta(x)=z_b(x)+h(x),\qquad q=\frac{Q}{W},\qquad \mathrm{Fr}=\frac{q}{\sqrt{g h^3}}.η(x)=zb​(x)+h(x),q=WQ​,Fr=gh3​q​.

η\etaη 是水面高程、zbz_bzb​ 是渠底高程、hhh 是當地水深，皆以m為單位；QQQ 是總流量（m³/s）、qqq 是單位寬流量（m²/s），Fr\mathrm{Fr}Fr 是福祿數。所有水面比較圖畫 η\etaη；摘要中的峰高則是水深 hhh 的峰值。

設定P0數值與意義
總流量／單位寬流量Q=0.05413786 m³/s；q=0.117691 m²/s
上、下游坡度S1=0.008682536356512494；S2=0.0007079080998610611，都是小數坡度
粗糙係數與局部損失Manning n=0.008；Cc=Ce=0
入口依S1算正常水深，hin≈0.07067283 m；Fr≈2
出口固定hout=0.1676558423973493 m；床高zout=0，故出口水面高程與水深數值相同
臨界水深hc≈0.11218613 m；入口小於hc，出口大於hc

完整的變床定義與方程在問題設定與方法講義。本次先重現原P0；不要直接改動cases/P0.json。

2. 設定P0與三種斷面間距

斷面是沿渠道取樣水位與幾何的位置。這一輪只改斷面間距，流量、床坡、粗糙係數與邊界皆不變。0.5、0.25、0.125 m分別有61、121、241個斷面，因為包含兩端。

入口仍由實際S1計算正常水深。HEC使用總流量Q，不能填0.117691這個單位寬流量。

在Notebook執行以下整格：

case = lab.load_case(CASE_ID)
spacings = [0.5, 0.25, 0.125]
show_table([{"parameter": k, "value": case[k]} for k in
            ["length_m", "width_m", "Q_m3s", "S1", "S2", "n", "hin_m", "hout_m"]])
save_json(work / "input.json", dict(student=STUDENT_ID, case=case, spacings_m=spacings))

3. 先跑三次Python標準步法

下面會依序執行三次SS，保存三個獨立資料夾並疊圖。列表的xJ_m取自每一次實際解的動量跳接，不使用共用細網格參考位置。越細的斷面越接近12.16 m；稍後HEC也要逐一做相同間距。

在Notebook執行以下整格：

ss_runs = [lab.run_method(case, "ss", dx=dx, output=work / "runs") for dx in spacings]
ss_rows = []
for dx, folder in zip(spacings, ss_runs):
    jump = read_json(folder / "summary.json")["checks"]["jump"]
    ss_rows.append(dict(dx_m=dx, sections=int(round(30/dx))+1,
                        xJ_m=jump["x_m"], h1_m=jump["y1_m"], h2_m=jump["y2_m"]))
show_table(ss_rows)
save_rows(work / "SS_spacing.csv", ss_rows)
figure = plot_compare(ss_runs, work / "SS_figures")
display(Image(filename=str(figure)))

5. 在HEC-RAS 6.6開檔，核對幾何

從這一步切換到Windows的HEC-RAS，不在Notebook執行。保持Notebook開著。依安裝頁第5步，把本次整個HEC_projects複製到Windows本機，再在Windows複本計算。記下P0_B_八碼，不要只傳.prj。

  1. 啟動HEC-RAS 6.6，用Help → About記錄版本。主視窗File → Open Project，選Windows複本中的HEC_projects\\dx0p5\\P0.prj；Ubuntu印出的路徑用來找到來源資料夾。
  2. 選Options → Unit System，確認SI（Metric）。開啟Edit → Geometric Data，再進入Cross Section。
  3. 河道SlopeChannel、河段Main。River Station從入口30遞減至出口0。本教材的下游坐標為 x=30−River Stationx=30-\mathrm{River\ Station}x=30−River Station。
  4. 在入口、轉坡段、出口各看一個斷面。Station/Elevation應是四個點：(0,zb+2),(0,zb),(0.46,zb),(0.46,zb+2)(0,z_b+2),(0,z_b),(0.46,z_b),(0.46,z_b+2)(0,zb​+2),(0,zb​),(0.46,zb​),(0.46,zb​+2)。它們構成垂直側壁；兩個底點須同高。
  5. 左右Bank Stations為0與0.46 m；Manning n=0.008；Contraction與Expansion均為0。相鄰斷面通道長度為0.5 m（最下游沒有下一段）。

保存幾何與單位畫面。若6.6無法讀取某個檔案，先停止並保存訊息交助教，不要以猜測欄位值繼續。所有核對值也在各子資料夾的sections.csv與expected.json。

6. 設定流量、兩端邊界與Mixed求解

  1. Edit → Steady Flow Data。確認只有一個P0流量剖面；入口總流量為 0.0541379 m3/s0.0541379\,\mathrm{m^3/s}0.0541379m3/s（HEC文字格式捨入後）。
  2. 點Reach Boundary Conditions。上游選Normal Depth，填斜率0.008682536356512494；下游選Known W.S.，填0.1676558423973493 m。這是水面高程，因本案出口床高為0才與尾水深度相等。
  3. 保存流量。主視窗Run → Steady Flow Analysis，核對幾何與流量均為本次P0，Flow Regime選Mixed（混合流）。
  4. Options → Friction Slope Methods選Average Friction Slope（摩阻坡度算術平均）。Options → Set Calculation Tolerances核對：Standard Step Tol與Critical Tol均為0.00001 m、Max Error Tol=0.0001 m、最多100次、Flow Tol Ratio=0.000001。
  5. 按Compute。等完成後保存計算訊息／警告，並到View → Water Surface Profiles看沿程水面。不要把「執行完成」當成無警告或已驗證。

預期入口Fr約2、出口Fr約0.547，水躍大致在x=12 m附近。具體HEC結果必須以你的實際運算為準；遇到critical depth替代或警告要保留。

Mixed流態與雙邊界的用途可查USACE 6.6技術手冊。圖形介面名稱及可選項以6.6實機為準，更多設定說明見本包6.6核對頁。

7. 匯出真實結果，整理四欄CSV

  1. 主視窗View → Profile Summary Table。只選本次P0計畫、P0剖面及SlopeChannel/Main河段，顯示全部斷面。
  2. 使用標準表或自訂表，包含River Sta、W.S. Elev、Froude # Chl及Q Total。Options內確認Metric；調整顯示小數位，水面高程至少6位、流量至少7位、Fr至少4位。
  3. 用表格視窗File → Copy to Clipboard複製，貼到試算表並先保存原始表。不要把畫面上四捨五入成0.05的Q當成原始流量。
  4. 另建四欄，依序命名 river_station,water_surface_m,Fr,Q_m3_s。從原表複製對應的數值列，移除重複標題、單位列、其他河段／剖面。不要自行填入Python水面。
  5. 另存「CSV UTF-8（逗號分隔）」，dx0p5應有61筆資料加1列表頭，先保存到Windows本次工作資料夾的HEC_exports/P0_dx0p5.csv，再複製回Ubuntu同一次work/HEC_exports/P0_dx0p5.csv（work就是步驟1的P0_B_八碼資料夾）。

9. 放大水躍區並畫水面差

整體水面幾乎重合時仍可能有水躍位置差。下格讀取比較器剛產生的comparison.csv，左圖看x=10–15 m，右圖畫 ηHEC−ηSS\eta_{\mathrm{HEC}}-\eta_{\mathrm{SS}}ηHEC​−ηSS​（mm）。它只處理本次已完成的真實HEC資料。

HEC在相鄰斷面間由Fr>1轉為Fr<1時，只能確定跳接落在一個區間。不要用連線的斜度估計物理水躍長度；也不要把區間中點當成精確跳接點。

在Notebook執行以下整格：

import matplotlib.pyplot as plt
# 每一間距只取本次最新的比較資料夾。
for key in ["dx0p5", "dx0p25", "dx0p125"]:
    candidates = [p for p in work.glob("compare_" + key + "_*")
                  if (p / "comparison.csv").is_file()]
    if not candidates:
        continue
    folder = max(candidates, key=lambda p: p.stat().st_mtime_ns)
    a = np.genfromtxt(folder / "comparison.csv", delimiter=",", names=True)
    fig, ax = plt.subplots(1, 2, figsize=(11, 4), layout="constrained")
    ax[0].plot(a["x_m"], a["eta_ss_m"], label="Python SS")
    ax[0].plot(a["x_m"], a["eta_hec_m"], "o-", ms=3, label="HEC-RAS 6.6")
    ax[0].set(xlim=(10, 15), xlabel="x (m)", ylabel="Water-surface elevation (m)")
    ax[0].legend()
    ax[1].plot(a["x_m"], 1000*a["difference_m"])
    ax[1].axhline(0, color="gray", lw=0.8)
    ax[1].set(xlabel="x (m)", ylabel="HEC minus SS (mm)")
    for panel in ax: panel.grid(alpha=0.2)
    fig.savefig(folder / "detail_and_difference.png", dpi=180)
    fig.savefig(folder / "detail_and_difference.pdf")
    display(fig)
    plt.close(fig)

10. 判讀與繳交

逐一列出三種間距、配對SS的xJ、HEC全部跳接區間、全渠道水面RMSE與最大差，以及警告。沒有上游超臨界轉下游次臨界的區間時記錄N/A並檢查；多個區間時全部保留。

RMSEη=1m∑i=1m(ηHEC,i−ηSS,i)2.\mathrm{RMSE}_{\eta}=\sqrt{\frac{1}{m}\sum_{i=1}^{m}(\eta_{\mathrm{HEC},i}-\eta_{\mathrm{SS},i})^2}.RMSEη​=m1​i=1∑m​(ηHEC,i​−ηSS,i​)2​.

m是配對斷面數。這是兩模式的差異，不是對實驗的誤差。跳接稍微位移時，局部最大差可能很大；需連同區間判讀，不能僅靠單一RMSE下結論。

判讀句型：「在0.5、0.25、0.125 m斷面下，HEC跳接分別位於……，配對SS位置為……。加密後區間／水面差呈現……。計算出現／未出現……警告，因此本比較支持……，尚不能支持真實水躍長度。」沒有實際HEC輸出時，最後一段明寫待實機完成。
