成果報告與可重跑資料的繳交方式

教材入口完整講義問題設定三種方法案例分工結果判讀P0操作示範符號表

報告的目標是讓另一位同學讀完後，知道你算了什麼、如何重跑，以及哪些結論有證據支持。

第一組比較標準步法（SS）、聖維南方程（SV）與定常壓力近似Boussinesq模型（B）；第二組比較Python標準步法與HEC-RAS 6.6。兩組都需交共同P0及自己的低、高水準案例。指標定義見結果判讀。

1. 建立繳交資料夾

A1_P1_v01/
  report.org               個人報告的可編輯文字原檔
  run_register.csv         每次計算的輸入、數值設定與狀態
  metrics.csv              最後採用的指標，以及N/A的原因
  runs/                   原始執行資料夾，保留輸入與輸出
  figures/                圖表及產生圖表的程式／Notebook
  hec/                    第二組另交專案、計算訊息及原始輸出
  submission_status.json  準備器列出的草稿狀態與缺項

Org是一種純文字大綱格式，可用一般文字編輯器開啟。可另外繳交PDF排版報告，但可重跑的原始資料與文字檔也要保留。不要加入 .venv、.tools 等軟體環境資料夾。

# 以下在套件根目錄執行；把路徑換成真正的計算資料夾
.venv/bin/python submission.py prepare A1 runs/你的計算資料夾 --output submissions/A1_P1_v01
# 填完報告、指標與圖表後再壓縮
.venv/bin/python submission.py zip submissions/A1_P1_v01

可在prepare後選多個資料夾。程式只接受該學生的P0及個人兩個變體，並列出缺少的案例／方法；它不會自動認定網格敏感度已完成。第二組另自行加入 hec/ 證據。重交請用v02等新名稱。

2. 報告按這八個問題寫

  1. 你在研究什麼？寫出物理問題、你改的因子、預期趨勢與理由。
  2. 你算的是哪一條渠道？列三條件的幾何、總流量、粗糙度、兩端邊界及初始水面；單位不可省略。
  3. 方法如何計算？第一次出現時寫完整名稱與縮寫；列出實際使用的LaTeX方程式，解釋主要符號與假設。
  4. 共同基準是否重現？說明P0設定、與封存資料的差異，以及未完成的檢查。HEC需附實際版本與運算記錄。
  5. 物理因子改變後發生什麼？呈現完整及局部水面、位置／水深對因子的趨勢。
  6. 數值設定影響多少？分別比較解析度與時間步；第一組另做B on/off與固定 λΔx\lambda\Delta xλΔx，第二組列斷面警告與跳接區間。
  7. 哪些量穩定、哪些仍不確定？說清楚多重交越、峰數不足、時間波動或失敗原因；不要只給一個總「誤差」。
  8. 別人如何重跑？列資料夾、輸入檔、程式版本、繪圖步驟與跨組核對結果。

3. 至少需要哪些圖表？

  • 三條件參數表：顯示改變量與固定量；入口福祿數與躍前福祿數分開。
  • 全渠道與局部水面圖：縱軸 η=zb+h\eta=z_b+hη=zb​+h，同一實際座標，不先平移對齊。
  • 水躍位置與外側平均水深的參數趨勢圖。
  • 網格／斷面與時間步敏感度表，列出比較量與相對差的分母。
  • 第一組另交峰高、峰位、峰距、峰谷差序列及耗散對照；第二組另交HEC計算訊息與跳接區間。

4. 指標表怎麼填？

metrics.csv 的 position_definition 要填你使用「比力跳接」、「唯一50%上穿點」或「相鄰斷面區間」。單一數值與區間不能不加說明地放在同一欄比較。N/A必須在 NA_reason 寫原因，例如「有三個50%上穿點」或「可辨峰谷不足四組」。

每張圖的圖說需能單獨閱讀，例如：「P2H，尾水為基準1.05倍；SS為標準步法，SV為時段平均，B為定常壓力近似；圖示水面高程，未作水平平移。」再補上解析度、CFL及耗散倍率。

5. 結論如何拿捏？

本專題重點是條件一致、證據可重跑、指標定義清楚與水理解釋。位置 0.05 m0.05\,\mathrm{m}0.05m、外側水深 2%2\%2% 是討論尺度；波動尚未穩定也可以成為有價值的結果，前提是完成對照、保存證據並說明限制。

不要把本案例的模型差異稱成實驗誤差；不要把數值上升寬度寫成已驗證的翻滾區長度；不要用增加Manning粗糙度來隱藏尚未解釋的波動。
