水躍之工程水理分析

第二組 · 18 週大學部專題 · 更新 2026-10-14

用教師提供的 Python standard-step 程式與 HEC-RAS 案例，研究工程水理如何預測水面線、水躍位置及水頭變化，並解釋邊界條件與斷面配置造成的差異。

現在可以開始： 固定 GC1991 Test 4 的 Python 教材已備妥。HEC-RAS 的共用水平 mixed-flow 範例尚待教師交付。

研究目標

  1. 說明比能、比力、共軛水深與標準步法如何決定急流／緩流分支及水躍匹配位置。
  2. 在相同物理輸入下，比較 Python 與 HEC-RAS 的水面線、位置判定及工程水頭變化。
  3. 區分邊界條件、斷面間距、計算選項與工程假設造成的差異，提出適用範圍說明。

核心問題是：給定流量、渠道阻力與尾水後，兩種工程方法是否得到相近結果？若不同，差異來自哪個環節？

工作內容

工作 學生要做的事 教師提供與確認
G2-1 古典水理 手算臨界水深、共軛水深、比力與能量損失，對照 Python 函式 選讀教材、已知答案與單位／符號
G2-2 標準步法 重現固定 Test 4，畫急流／緩流分支、比力差及匹配位置 現有程式與基準；水躍用匹配處理，不跨躍使用光滑能量步進
G2-3 HEC-RAS 配對 建立相同渠道，記錄版本、計算設定及原始匯出水面線 可執行的水平 mixed-flow 範例與邊界對應
G2-4 有限比較 比較指定的兩組斷面間距；新案例版交付後才改尾水 合理間距、允許輸入範圍及參考檢查
G2-5 解釋與交付 比較 Python／HEC-RAS，再與第一組 SV 基準比對 共同比對規則與原始資料

逐項核對流況、斷面順序、邊界、能量／動量係數及局部損失設定。兩個程式不能完全採用相同設定時，明列差異，避免將其誤認為方程效果。

Manning n 使用共同指定值，代表渠道阻力；本學期不以增大 n 吸收所有水躍損失，也不以調整 n 使各條曲線重合。學生修改指定的 Python 分析、繪圖與經開放的案例輸入，不需從零建立求解器。

預期成果

  • HEC-RAS 案例： 可執行的專案檔、版本與輸入設定表，以及原始匯出資料。
  • Python 分析 Notebook： 手算核對、兩分支水面、比力匹配圖與可重現步驟。
  • 工程比較圖表： Python–HEC-RAS 水面與位置比較，附斷面間距及核准變例的影響。
  • 研究報告與簡報： 說明工程方法能預測的量、適用範圍與尚未釐清的差異。

最低完成範圍是固定水平案例的可重現工程比較。HEC-RAS 未交付時先完成 G2-1、G2-2 與交換資料格式，該項仍列待完成。坡度轉折須等教師補足正常水深、坡床程式與配對案例後再延伸。

與第一組如何比對

第一組「水躍之深度平均模擬」負責 SV、B 型與待交付的 SSWE。第二組先彙整共同輸入，第一組覆核；從 Python standard-step–SV 比較起步，再加入其餘可用方法。

交換數值資料而非圖片。水深採相同量測站位；HEC-RAS 水躍位置保留相鄰斷面區間，Python 保留比力匹配點。兩組分別產生同一張疊圖，依輸入／邊界、數值／取樣、方程／閉合的順序解釋差異。

完整輸入、指標、交付欄位及週次見共同比對與 18 週時程。

本週先做什麼

  1. 進入 GC1991 實驗室，跑通固定 Python standard-step 範例。
  2. 閱讀方程與方法，完成一組古典水躍手算與程式核對。
  3. 交付兩分支水面圖與共用輸入表，確認單寬流量 q 與 HEC-RAS 所需總流量 Q 的區別。

週次依實際教學進度對應；組別調整不代表重新開始學期。每週短會各帶一張圖、一個解釋與一個待釐清問題。
