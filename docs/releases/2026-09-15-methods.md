# v1／2026-09-15 方法文件修訂版

本次依教師要求，使 `gc1991-lab/docs/methods.md` 成為可獨立閱讀的教學章節，並同步更新 GitHub Pages 與完整教材下載。這是文件修訂；計算核心、案例輸入、實驗資料及既有參考結果均未改動。

## 內容與核對依據

- 增補符號、單位、Manning 摩阻、比能、比力與臨界水深。
- 展開 standard-step 的能量殘差、二分求根、雙分支匹配、共軛深與能量損失推導；提供 Test 4 可執行算例。
- 說明 Saint-Venant 守恆律、重建、Kurganov 通量及顯式中點法。
- 從垂向連續式、加速度與壓力積分推導 GC1991 Boussinesq 型方程，區分完整非定常式與實際採用的穩態 B 修正；補上線性色散關係。
- 逐項對照固定自訂核心的差分、Rusanov、曲率感測器、人工輸運、兩階段更新、半格邊界與收支。說明全域守恆不代表局部節點流速已驗證。
- 加入邊界與初始條件、時間平均、誤差解讀、程式位置對照，以及 8 題自我檢核與簡答。

原論文控制式已核對 Gharangik & Chaudhry (1991) pp.1197–1198；工程背景核對 HEC-RAS 官方能量／動量方法文件；SV 與自訂算法核對隨教材封存的原始碼。參考文獻連結詳列於方法章。未重製論文圖版，未改動 Zotero PDF 或原始資料。
