# v1／2026-09-16 Windows 安裝說明修訂版

依教師要求，將 Windows／WSL 安裝說明改寫為適合初次使用 Linux 與命令列的學生教材。Mac 虛擬機問題不在本次內容中。

## 文件改動

- 區分一般／系統管理員 PowerShell、Ubuntu、Windows Terminal 與 Windows 瀏覽器；說明提示字串、逐行輸入、貼上與中斷。
- 補齊重新開機後的 Ubuntu 啟動、Linux 帳號與密碼設定、已裝發行版名稱及 WSL 2 版本確認。
- 明確先執行 `cd ~` 再開啟檔案總管，避免從 PowerShell 啟動後在 Windows 磁碟目錄編譯。
- 提供固定教材 ZIP 下載入口、Windows 到 Linux 家目錄的複製流程、檔名及解壓層級檢查。
- 依實際腳本說明必要工具、安裝成功訊息、GC1991 Lab 核心、實際 token 網址，以及儲存／停止服務流程。
- 每步附完成判準；常見失敗依 WSL、Ubuntu／教材、Notebook 連線分組。
- 示意輸出不提供複製按鈕；指令區塊保留複製功能。長篇文件章節錨點直接放在可見標題，並保留既有自動產生的別名。

## 核對與測試範圍

已核對 Microsoft WSL 安裝、基本指令、帳號、檔案系統與網路文件，Ubuntu 24.04 WSL 與套件資料，以及 Jupyter 官方 token 說明。教材特有的行為逐項對照 `setup.sh`、`start_lab.sh`、`scripts/setup_basilisk.py` 與 Notebook 核心設定。來源連結集中列於學生安裝頁末。

本機靜態及瀏覽器檢查：11 頁、293 個站內連結與錨點、全部 27 個指令／輸出區塊逐字保留、Bash 語法、ZIP 內容及校驗皆通過。桌面與 390 px 手機版無頁面水平溢出，章節跳轉可定位到可見標題；四個示意輸出沒有複製按鈕。
