# 2026-10-22 正式發布：坡度渠道教學包 v1.3

經教師核准，將已審閱的獨立教學講義、兩組 P0 逐步示範、十人操作單、成果繳交格式、v1.3 ZIP 與 Windows／WSL 驗收紀錄整合到正式首頁。GC1991 原教材、45 個封存檔案及下載 ZIP 完整保留。

學生沿用已完成 GC1991 的 Windows／WSL／Ubuntu，在相鄰的 slope-lab 資料夾安裝專用環境。兩組皆在 Ubuntu 執行 Python；第二組另在 Windows 使用 HEC-RAS 6.6。
