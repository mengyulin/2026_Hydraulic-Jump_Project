學生可以怎麼開始？

  1. 保留 ~/gc1991-lab；在 Linux 家目錄另建 ~/slope-lab，不複製舊 .venv。
  2. 依安裝頁執行一次 setup，確認 Slope Channel Lab 核心。
  3. 兩組都由原 Ubuntu 啟動各自 P0，使用 Windows 瀏覽器連線。
  4. 第二組把完整 HEC 專案複製到 Windows，完成 HEC-RAS 6.6 計算後才回傳真實匯出。
