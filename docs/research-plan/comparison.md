[第一組](group-1.md)比較標準步法、SV與B；[第二組](group-2.md)比較Python標準步法與HEC-RAS 6.6。以坡度變化矩形渠道P0為共同基準，各組五人分別研究五個單因子系列。

<a id="cases"></a>
## 共用案例

每人完成P0與自己的低、高水準，合計三個條件。兩組同編號配對：A1／B1研究上游坡度，A2／B2研究尾水，A3／B3研究轉換長度，A4／B4研究下游坡度，A5／B5研究粗糙度。全班共有11種不同物理設定。

- [問題設定](../../slope-lab/docs/problem.html)：唯一的完整P0輸入表、坐標與邊界說明。
- [案例設計](../../slope-lab/docs/design.html)：五系列的完整參數與數值控制。
- [P0操作示範](../../slope-lab/docs/p0_demo.html)：各組先完成一次可重現流程。
- [GC1991實驗室](../../gc1991-lab/index.html)：保留的驗證練習，不能混用其尾水、床高與平均時間。

<a id="workflow"></a>
## 交換與比對流程

1. **確認相同物理案例。** 同編號同學核對JSON、單位、坐標、流量及邊界。HEC流量用總流量，另記文字檔捨入。
2. **各組完成P0。** 第一組完成三模式重現；第二組完成Python與HEC實機匯出，未完成的部分明確列待辦。
3. **交換數值資料。** 每次附案例、方法、解析度、時間／平均窗、位置定義與檢查狀態。
4. **各自讀同一份資料製圖。** 統一畫水面高程，保留完整圖與水躍局部圖；不水平平移曲線。
5. **解釋差異。** 依序查輸入與邊界、離散與時間變動、方程與尚未描述的物理機制。
6. **交叉重現。** 每組依對方說明重跑至少一份分析，確認圖表可追溯後再寫結論。

<a id="metrics"></a>
## 如何讀取比較量

| 項目 | 跨組共同做法 |
|---|---|
| 水面 | 交換x、渠底高程、水深及水面高程；圖使用水面高程，不將水深圖誤當高程圖 |
| 水躍位置 | 分別列SS比力匹配點、HEC相鄰斷面區間、SV／B唯一50%上穿點 |
| 外側水深 | 按同一個SS參考所定義的取樣區間；不以指定尾水冒充獨立預測 |
| 波峰與波尾 | 第一組保留全部可辨峰谷與樣本數；多重交點或峰數不足時用N/A |
| 時間／解析度 | 清楚區分重現、定常性與網格穩定；B短續算不是完整物理時間驗證 |
| 水面差 | 配對模式之差；P0沒有實驗量測，不宣稱物理誤差或真實滾流長度 |

精確公式、取樣區間、指標欄位與限制以[結果判讀章](../../slope-lab/docs/results.html)為準；此處只保留跨組規則。繳交欄位與資料夾結構以[成果繳交頁](../../slope-lab/docs/submission.html)為準。

<a id="schedule"></a>
## 18週分工

週次是學期內的相對階段，教師可依進度調整；本次更新不代表重啟學期。第4、8、12、16、18週檢視共同證據。

| 週次 | 第一組：SS／SV／B | 第二組：SS／HEC-RAS | 共同交付 |
|---|---|---|---|
| 1–2 | 安裝、讀問題設定，完成P0三模式示範 | 安裝、P0 Python與HEC實機預試 | 輸入表、環境／版本記錄 |
| 3–4 | 整理方程假設、讀水面與時間診斷 | 古典水理核對、讀比力匹配與HEC區間 | P0圖表與一頁方法說明 |
| 5–6 | 低、高變體起步檢查，再進主要解析度 | 低、高變體建立相同輸入的配對專案 | 三條件完成清單 |
| 7–8 | 完成1024／2048主要比較 | 完成三種斷面間距比較 | 期中水面圖、位置與水深趨勢 |
| 9–10 | 選一變體做時間步與B控制對照 | 檢查計算選項、警告與加密趨勢 | 來源明確的差異解釋 |
| 11–12 | 分析B波峰、峰距及波尾限制 | 與同編號夥伴核對交換資料 | 跨組比較圖、缺項／失敗表 |
| 13–14 | 綜合物理變因與數值影響 | 綜合邊界、間距與工程假設 | 五因子的結果整理 |
| 15–16 | 撰寫報告，重現第二組分析 | 撰寫報告，重現第一組分析 | 共同結論初稿及重跑證據 |
| 17–18 | 報告與簡報定稿 | 報告與簡報定稿 | 兩份組別報告、個人成果與共用資料 |

<a id="gates"></a>
## 交付與完成判準

| 交付點 | 完成證據 |
|---|---|
| G0 問題與環境 | 能說明P0輸入，成功開啟對應Notebook與工具 |
| G1 共同基準 | 第一組P0重現；第二組真實HEC匯出與配對分析，未完成明列 |
| G2 個人案例 | 每人P0＋低、高水準，保存結果及失敗分類 |
| G3 數值對照 | 第一組指定解析度／控制；第二組三種斷面與計算紀錄 |
| G4 跨組比對 | 同案例疊圖、位置定義、模型差異與限制 |
| G5 結案 | 個人成果可追溯，兩組報告完整，另一組可重現至少一份分析 |

不把「B波形必須完全收斂」作為專題完成的必要條件；須如實指出哪些量穩定、哪些仍受網格或耗散影響。HEC實機未就緒時先完成Python部分並由教師處理環境，不以合成資料填補。大規模CFD、完整GN、剪切淺水方程及新閉合模型不列為本次必做範圍。
