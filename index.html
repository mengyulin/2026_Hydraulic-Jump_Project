02 / Research questions

我們想理解什麼？

主題是渠道從陡坡轉為緩坡時，急流如何轉成緩流，以及工程計算能解釋到哪裡。

xt

水躍發生在哪裡？

尾水、底床坡度與邊界條件如何改變水躍位置？不同方法定位水躍的方式有何差異？

y₂ & ΔH

水深與能量如何改變？

共軛水深與總水頭損失如何連到計算結果？哪些差異可以由水理假設解釋？

Model ↔ Evidence

比較結果代表什麼？

分清楚程式重現、模型間一致與實驗驗證。圖形接近，仍需檢查數值設定與適用範圍。

03 / Semester roadmap

18 週，從重現到解釋

依既有學期規劃安排，以週次表示。後續工作須等教師完成對應教材，再依課堂進度調整。

週次 學習與研究工作 留下的成果
01–02 認識問題、安裝環境、重現 GC1991 範例 參考比較圖、輸入與輸出說明
03–04 閱讀 Python 水理公式，核對比能、比力與共軛水深 手算與程式對照的 Notebook
05–06 使用教師另行開放的案例，一次改一個參數 預測、比較圖與變更紀錄
07–08 建立匹配的 HEC-RAS 案例，比較斷面間距 期中 Python–HEC-RAS 比較
09–10 操作提供的 Basilisk 案例，閱讀邊界與數值設定 基準與一組變例、診斷圖
11–12 比較共同基準，完成教師指定的敏感度與驗證練習 三模型比較與獨立的驗證說明
13–14 完成小型坡度／尾水矩陣 5–9 組可追溯案例與結果圖
15–16 做一項有目的的 Python 分析改動，整理主要發現 改動前後比較、報告草稿
17–18 交換案例重跑，完成報告與簡報 程式、輸入、圖表與重現指南

本學期重點是可重現的比較與水理解釋。新閉合公式、機器學習及大規模三維 CFD 不列為必做成果。

05 / Student outcomes

交付可以被重現的結論

每組結果都應回答：使用什麼設定、改了什麼、觀察到什麼，以及這個解釋有哪些限制。

  • 保留案例 ID、輸入條件、方法與數值設定。
  • 圖中標示座標、單位、圖例與資料來源。
  • 同時報告成功、失敗及尚未確認的結果。
  • 讓另一位同學能依說明重跑至少一個案例。

第一次實驗的交付

  • 三種方法與實驗的比較圖。
  • RMSE 表及各方法的計算設定。
  • 用比力說明 standard-step 的零長度水躍。
  • 說明水面較接近實驗，為何不足以驗證內部流速。
